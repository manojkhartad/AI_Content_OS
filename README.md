# 🤖 AI Content OS

AI Content OS is a modular AI-powered content generation system built using Python and Google's Generative AI SDK.

The goal of this project is to build an intelligent multi-agent system capable of researching topics, planning content, generating high-quality outputs, storing memory, and orchestrating complete content workflows.

---

# 🚀 Current Features

- Research Agent
- Brain Module
- LLM Client
- Story Workflow
- Memory Manager
- Modular Architecture
- GitHub Version Control

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/manojkhartad/AI_Content_OS.git
```

Go into the project

```bash
cd AI_Content_OS
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# 🔑 Configuration

Create a file

```
config/settings.py
```

Add your Google AI API Key

```python
GEMINI_API_KEY = "YOUR_API_KEY"
```

---

# ▶️ Run

```bash
python main.py
```
